# 今日任务同步版（Sean / Nico）

一个简洁的三列任务管理面板，支持双人任务管理、天气信息、番茄钟计时和云同步。

## 功能

- **双人任务面板** — Sean 和 Nico 各自独立的任务列表
- **重要性标注** — 红色（重要）/ 黄色（普通）/ 绿色（轻松）
- **拖拽排序** — 未完成任务可拖动调整顺序
- **番茄钟计时** — 每个面板可独立倒计时，结束后自动累计用时
- **天气信息** — 自动定位或手动选择城市，显示实时天气与未来24小时降雨预测
- **活动推荐** — 随机推荐活动，一键添加到任务列表
- **云同步** — 基于 Supabase 的实时同步，多设备间保持数据一致

## 使用

直接打开 `index.html` 即可使用，所有数据存储在浏览器本地及云端。

## 技术栈

- 原生 HTML / CSS / JavaScript
- [Supabase](https://supabase.com/) 公共同步
- [Open-Meteo](https://open-meteo.com/) 天气 API
